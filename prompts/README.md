# 提示词配置

SJTUClaw 启动时读取本目录中的三份提示词：

| 文件 | 用途 | 是否适合自定义 |
| --- | --- | --- |
| `soul.md` | 助手身份、语气和协作风格 | 是，推荐从这里调整人格 |
| `system_prompt.md` | 工具调用、审批、安全边界和执行证据 | 谨慎修改 |
| `compact_prompt.md` | 长对话压缩时的摘要结构与保留规则 | 通常无需修改 |

公开仓库提供的是可直接运行的通用默认值，不包含作者的私人聊天内容或个人化角色设定。

修改 `soul.md` 后需重启 CLI 或 Gateway。自定义人格不应覆盖以下规则：

- 不伪造工具调用或执行结果；
- 写操作遵守 Workspace 和 Approval；
- 不泄露密钥、令牌和无关个人信息；
- 文件、附件和网页结论保留可追踪来源。

如果希望保留自己的版本，可以在仓库外备份，或在自己的私有分支中维护；不要把含有
私人身份、凭证或聊天片段的提示词提交到公开仓库。
