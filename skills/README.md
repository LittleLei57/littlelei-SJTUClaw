# 内置 Skills

公开仓库只包含本项目的六个提示词型 Skills：

| Skill | 用途 |
| --- | --- |
| `course-report` | 课程报告草稿 |
| `document-reader` | 文档阅读 |
| `material-summary` | 材料总结 |
| `pdf-reader` | PDF 阅读 |
| `presentation-outline` | 演示提纲 |
| `repository-briefing` | 仓库导读 |

本机安装的 `agent-browser`、`guizang-ppt-skill`、`pptx`、`xlsx` 及后续安装的
其他第三方 Skills 不随 Git、Docker 或发布目录分发。不影响核心聊天、工具、审批
和以上内置 Skills；第三方 Skill 的安装和使用需自行确认其依赖与许可。
