# Repository review checklist

## 身份与范围

- [ ] 仓库、owner、ref/commit 已确认
- [ ] 用户希望的分析深度已确认
- [ ] API 限流、私有权限或缺失路径已显式记录

## 最小证据集

- [ ] 顶层目录与 README
- [ ] 依赖/构建清单
- [ ] 启动入口
- [ ] 核心编排代码
- [ ] 数据结构与持久化
- [ ] 代表性测试或 CI

## 长上下文纪律

- [ ] 先目录后文件，按问题渐进读取
- [ ] 长资源根据 `nextOffset` 继续读取
- [ ] 没有把截断内容误认为完整文件
- [ ] 没有重复读取已经取得且未变化的证据
- [ ] 中间结论标记为事实、推断或待确认

## 最终交付

- [ ] 启动命令来自真实文档/配置
- [ ] 核心执行链有文件或函数证据
- [ ] 风险与未知项没有被包装成已完成能力
- [ ] 文件路径或 GitHub URL 可追溯
