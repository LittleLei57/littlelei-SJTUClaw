# 打工喵桌宠主题

`workcat-sprites.png` 是 SJTUClaw 项目内使用的原创桌宠精灵图，包含 2×3 六个状态：

1. 待机
2. 招手
3. 思考
4. 使用工具
5. 睡眠 / 离线
6. 回复 / 庆祝

素材由 OpenAI 图像生成工具根据项目需求生成，不是“月薪喵”官方素材，也不复刻该商业
IP。这样可以安全地随项目源码分发。若未来取得月薪喵官方授权，只需按相同的 2×3
布局替换精灵图，无需改动桌宠交互代码。

精灵图坐标由 `web/pet.css` 中的 `background-position` 管理。桌宠的状态、待机动作和
交互逻辑位于 `web/pet.js`：空闲一段时间后进入持续小睡，单击会从挥手、伸懒腰、思考、
庆祝、被摸、蹦跶、左右探头、转圈、摇尾巴、击掌、打卡开工和鞠躬共 12 种短动作中
随机选择；Agent 请求模型和执行工具期间使用电脑姿态，收到回复时切换为庆祝姿态。
任意点击、输入或拖动都会将它从小睡中唤醒。
